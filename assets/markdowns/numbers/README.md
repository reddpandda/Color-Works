# numbers

Page-number icons, `01` to `99`, in four filled sets. Files are named `number_01.svg` to `number_99.svg`.

- [black-box-filled/](black-box-filled/)
- [white-box-filled/](white-box-filled/)
- [black-circle-filled/](black-circle-filled/)
- [white-circle-filled/](white-circle-filled/)

[number-generator.html](number-generator.html) builds these icons. Download it and open it in a browser: it shows every style, and the download button makes a ZIP with one folder per style, using the same folder names as above. It also builds the outline styles, `0`, `00` and the plain `1` to `9`, which are not stored in this repository.

The digits are paths from JetBrains Mono Bold (SIL Open Font License 1.1), so the icons need no font to display.
